# Proposal website: how to edit and host it free on Vercel

## 1. Edit your details
Open index.html in any text editor (Notepad is fine) and find the block that says
EDIT THIS PART ONLY. Change:
- herName, yourName, specialDate (already 6 November)
- whatsapp (your number with country code, digits only, e.g. 94771234567)
- youtubeId (the part after v= in your unlisted YouTube link) OR videoFile ("video.mp4")
- musicFile ("music.mp3", optional)
- timeline and reasons: your own memories and words. For photos, put the image files
  in this same folder and write the file name, e.g. photo: "us1.jpg"

Tip: upload the 1:10 video to YouTube as "Unlisted" and paste only its id.

## Photos for the hanging gallery
Make a folder called photos next to index.html and put your 10 pictures in it,
named 1.jpg, 2.jpg ... 10.jpg (or change the names and captions in the gallery list
inside the EDIT THIS PART block). Resize big phone photos to about 1000 px wide first,
so the page loads fast. Photos that are missing show a pink placeholder frame.

## 2. Test on your computer
Double-click index.html. Tap the envelope and go through every question.

## 3. Host free on Vercel (no coding)
1. Create a free account at vercel.com (sign in with Google or GitHub).
2. Go to vercel.com/new and choose to upload or drag in this folder
   (or push the folder to a GitHub repo and import it).
3. Framework Preset: "Other". Leave build settings empty. Click Deploy.
4. Vercel gives you a link like your-name.vercel.app. Send her that link.
5. Optional: Project Settings > Domains lets you rename it, e.g. forher-name.vercel.app.

Test the link on your own phone before sending it. To change anything later,
edit index.html and deploy again.
